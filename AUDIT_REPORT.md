## 📊 ОБНАРУЖЕННЫЕ ПРОБЛЕМЫ

### 1. ❌ КРИТИЧЕСКАЯ: GET запрос к `/api/products/` не доходит до сервера

**Симптомы:**
- В логах видно только `OPTIONS /api/products/` (200 OK)
- GET запрос не виден в логах сервера
- Клиент получает таймаут через 15 секунд
- Товары не загружаются

**Причина:**
- Запрос блокируется на уровне ngrok или CORS
- Возможно, проблема с длинным URL или параметрами запроса
- Middleware не видит GET запрос

**Решение:**
- ✅ Добавлено логирование в middleware для `/api/products/`
- ⚠️ Нужно проверить, доходит ли запрос до сервера после перезапуска

---

### 2. ⚠️ ПРОБЛЕМА: Логика работы с главным ботом vs клиентскими ботами

**Текущая логика в `context.py`:**
1. Если `bot_id = None` (главный бот) → товары с `bot_id = None`
2. Если `bot_id = 7` (клиентский бот) → товары с `bot_id = 7`

**Проблема:**
- Когда клиент открывает магазин через клиентского бота, проверяется наличие товаров с `bot_id = 7`
- Если товаров нет для этого `bot_id`, показывается пустой магазин
- Нет fallback на главный бот для клиентов

**Текущее поведение:**
```
Клиент открывает через бота 7:
1. Проверяется наличие товаров с bot_id=7
2. Если нет → показывается свой магазин (viewer_id)
3. НО не показываются товары из главного бота (bot_id=None)
```

**Ожидаемое поведение:**
```
Клиент открывает через бота 7:
1. Проверяется наличие товаров с bot_id=7
2. Если нет → показываются товары из главного бота (bot_id=None) владельца
3. Если и их нет → показывается свой магазин
```

---

### 3. ⚠️ ПРОБЛЕМА: Синхронизация товаров может быть медленной

**Текущая логика в `get_products`:**
- При каждом запросе товаров выполняется полная синхронизация между главным ботом и всеми клиентскими ботами
- Это может занимать много времени при большом количестве товаров/ботов

**Проблема:**
- Синхронизация выполняется синхронно
- Может вызывать таймауты при большом количестве данных

### 4. ⚠️ ПРОБЛЕМА: Endpoint `/api/products/` не валидирует пользователя

**Текущая реализация:**
```python
@router.get("/", response_model=List[schemas.Product])
def get_products(
    user_id: int,  # Принимается напрямую из query параметра
    bot_id: Optional[int] = Query(None),
    ...
)
```

**Проблема:**
- `user_id` принимается напрямую без валидации через Telegram initData
- Нет проверки, что пользователь имеет право просматривать товары этого магазина
- Потенциальная проблема безопасности
