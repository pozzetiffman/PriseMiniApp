## НАЙДЕННЫЕ ПРОБЛЕМЫ:

### 1. ЗАКАЗЫ (`/api/orders/shop`)
**Проблема:** 
- Endpoint фильтрует заказы по `is_cancelled == False` (строка 422 в `orders.py`)
- Это означает, что **отмененные заказы не учитываются** в статистике
- Нужно считать **ВСЕ заказы** когда-либо созданные для магазина

**Текущий код:**
```python
orders = db.query(models.Order).options(
    joinedload(models.Order.product)
).filter(
    and_(
        models.Order.user_id == user_id,
        models.Order.is_cancelled == False  # ❌ ПРОБЛЕМА: исключает отмененные
    )
).order_by(models.Order.created_at.desc()).all()
```

**Решение:** Убрать фильтр `is_cancelled == False` или использовать отдельный endpoint для статистики

---

### 2. РЕЗЕРВАЦИИ (`/api/reservations/user/me`)
**Проблема:**
- Endpoint фильтрует по `is_active == True` и `reserved_until > datetime.utcnow()` (строки 628-629)
- Это означает, что **старые/неактивные резервации не учитываются** в статистике
- Также endpoint возвращает резервации, где пользователь - владелец ИЛИ резервирующий
- Для статистики магазина нужны только резервации товаров магазина (user_id == shopOwnerId)

**Текущий код:**
```python
reservations = db.query(models.Reservation).filter(
    and_(
        or_(
            models.Reservation.user_id == user_id,  # Владелец магазина
            models.Reservation.reserved_by_user_id == user_id  # Тот, кто зарезервировал
        ),
        models.Reservation.is_active == True,  # ❌ ПРОБЛЕМА: исключает неактивные
        models.Reservation.reserved_until > datetime.utcnow()  # ❌ ПРОБЛЕМА: исключает старые
    )
).order_by(models.Reservation.created_at.desc()).all()
```

**Решение:** 
- Использовать endpoint без фильтров по активности
- Фильтровать только по `user_id == shopOwnerId` (товары магазина)
- Или создать отдельный endpoint `/api/reservations/shop` для статистики

### 3. ИЗБРАННОЕ (`/api/favorites/count`)
**Проблема:**
- Endpoint фильтрует по `is_sold == False` и `is_hidden == False` (строки 223-224)
- Это означает, что избранное для **проданных/скрытых товаров не учитывается**
- Нужно считать **ВСЕ избранное** когда-либо добавленное для товаров магазина

**Текущий код:**
```python
count = db.query(models.Favorite).join(
    models.Product
).filter(
    and_(
        models.Favorite.user_id == user_id,
        models.Favorite.shop_owner_id == shop_owner_id,
        models.Product.is_sold == False,  # ❌ ПРОБЛЕМА: исключает проданные
        models.Product.is_hidden == False  # ❌ ПРОБЛЕМА: исключает скрытые
    )
).count()
```

**Решение:** Убрать фильтры по `is_sold` и `is_hidden` для статистики магазина (для владельца)
