# Расположение Bottom Sheet относительно меню

## Слои по z-index (вид сверху вниз)

```
┌─────────────────────────────────────────────────────────────┐
│  СЛОЙ 1: Меню (header)                                       │
│  z-index: 10010  ← всегда поверх всего                       │
│  position: fixed; bottom: 0; min-height: 64px                │
├─────────────────────────────────────────────────────────────┤
│  СЛОЙ 2: Bottom Sheet                                        │
│  z-index: 5000   ← поверх контента, но ПОД меню               │
├─────────────────────────────────────────────────────────────┤
│  СЛОЙ 3: Контент страницы (карточки, грид и т.д.)            │
│  z-index: 0                                                  │
└─────────────────────────────────────────────────────────────┘
```

---

## Схема по вертикали (вид сбоку)

### 1. Страница товара (product-page) — Bottom sheet постоянно видим

```
  ↑ top
  │
  │  ┌─────────────────────────────────────┐
  │  │  product-new-top-menu (шапка)       │
  │  └─────────────────────────────────────┘
  │  ┌─────────────────────────────────────┐
  │  │                                     │
  │  │  product-page-content               │
  │  │  (описание, цена, фото...)           │
  │  │  padding-bottom: 140px + safe-area  │  ← место под bottom sheet
  │  │                                     │
  │  ├─────────────────────────────────────┤
  │  │  BOTTOM SHEET (product-page)         │  z-index: 5000
  │  │  bottom: 64px + (-30px) = 34px      │  ← отступ от низа экрана
  │  │  (сидит НАД областью меню по высоте,│     не перекрывает меню
  │  │   но по z-index — под меню)          │
  │  ├─────────────────────────────────────┤
  │  │  МЕНЮ (header)                       │  z-index: 10010
  │  │  bottom: 0, height ~64px            │  ← всегда поверх
  │  └─────────────────────────────────────┘
  ↓ bottom (safe-area-inset-bottom)
```

**Переменные для страницы товара:**
- `--menu-height: 64px`
- `--bottom-sheet-offset: -30px` → низ панели: `bottom: 34px`
- Контент bottom sheet не заходит под меню (padding-bottom учитывает меню).

---

### 2. Страница избранного / главная — Bottom sheet выезжает по клику

```
  ↑ top
  │
  │  ┌─────────────────────────────────────┐
  │  │  Контент (карточки, грид)            │
  │  │                                     │
  │  ├─────────────────────────────────────┤
  │  │  BOTTOM SHEET (#cart-bottom-sheet)   │  z-index: 5000
  │  │  Контейнер: top:0, left:0, right:0,  │
  │  │  bottom:0 (на весь экран)            │
  │  │  .cart-bottom-sheet-content:         │
  │  │    bottom: 0                         │
  │  │    max-height: 80vh - 64px - 16px    │  ← не заходит под меню
  │  │    padding-bottom: 64 + 16 + safe    │  ← контент не под меню
  │  ├─────────────────────────────────────┤
  │  │  МЕНЮ (header)                       │  z-index: 10010
  │  │  bottom: 0                           │
  │  └─────────────────────────────────────┘
  ↓ bottom
```

Итог: bottom sheet занимает весь экран по площади, но по z-index рисуется под меню. Высота контента панели и отступ снизу рассчитаны так, чтобы визуально и по кликам не перекрывать меню.

---

### 3. Страница корзины (cart-page-new) — футер с кнопкой оформления

```
  ↑ top
  │
  │  ┌─────────────────────────────────────┐
  │  │  cart-new-top-menu                  │
  │  └─────────────────────────────────────┘
  │  ┌─────────────────────────────────────┐
  │  │  cart-page-content                  │
  │  │  padding-bottom: menu + 16 + 80 + safe │  ← место под футер
  │  ├─────────────────────────────────────┤
  │  │  ФУТЕР (#cart-new-footer)            │  z-index: 400
  │  │  bottom: 64px + 16px = 80px          │  ← визуально НАД меню
  │  ├─────────────────────────────────────┤
  │  │  МЕНЮ (header)                       │  z-index: 10010
  │  │  bottom: 0                           │
  │  └─────────────────────────────────────┘
  ↓ bottom
```

Только для корзины: футер позиционируется `bottom: calc(var(--menu-height, 64px) + 16px)`, по слоям остаётся под меню.

---

## Где в коде

| Элемент | HTML | CSS (style.css) |
|--------|------|------------------|
| Меню | `<header>` после cart-bottom-sheet | ~стр. 149–173, z-index 10010 |
| Bottom sheet (избранное) | `#cart-bottom-sheet` | ~8539–8635 |
| Bottom sheet (страница товара) | `#product-page-bottom-sheet` внутри `#product-page` | ~8637–8712 |
| Футер корзины | `#cart-new-footer` внутри `#cart-page-new` | #cart-page-new .cart-new-footer: bottom: menu + 16px |

**Важно:** у bottom sheet нет `transform`/`filter`/`opacity` на контейнере, чтобы не создавать свой stacking context и оставаться ниже меню по z-index.
