## 2. Мини-патчи (фрагменты до/после)

### Добавление переменных в :root

**Было (фрагмент после строки 23):**
```css
    --shadow-glass: rgba(0, 0, 0, 0.4);
    
    /* Blur эффекты */
```

**Стало:**
```css
    --shadow-glass: rgba(0, 0, 0, 0.4);
    
    /* Design tokens: цены и акцент */
    --color-price-cash: #E35E45;
    --color-price-card: #00A82E;
    --color-accent-rgb: 90, 200, 250;
    --bg-base: #1c1c1e;
    --bg-elevated: #2c2c2e;
    
    /* Blur эффекты */
```

### Пример замены цвета цены

**Было:** `color: #E35E45 !important;`  
**Стало:** `color: var(--color-price-cash) !important;`

**Было:** `color: #00A82E;`  
**Стало:** `color: var(--color-price-card);`

### Пример замены rgba-акцента

**Было:** `background: rgba(90, 200, 250, 0.1);`  
**Стало:** `background: rgba(var(--color-accent-rgb), 0.1);`

**Было:** `box-shadow: 0 4px 16px rgba(90, 200, 250, 0.15), ...`  
**Стало:** `box-shadow: 0 4px 16px rgba(var(--color-accent-rgb), 0.15), ...`

### Пример замены базового фона

**Было:** `background: linear-gradient(135deg, #1c1c1e 0%, #2c2c2e 50%, #1c1c1e 100%);`  
**Стало:** `background: linear-gradient(135deg, var(--bg-base) 0%, var(--bg-elevated) 50%, var(--bg-base) 100%);`
