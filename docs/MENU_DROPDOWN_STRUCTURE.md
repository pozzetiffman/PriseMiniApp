# Устройство выпадающего меню (main-menu-dropdown)

Кратко: как устроено меню, почему могли пропадать кликабельность и затемнение фона, и что исправлено.

---

## Разметка и слои

- **HTML** (`index.html`):
  - `#main-menu-dropdown.main-menu-dropdown` — контейнер на весь экран, по умолчанию `style="display: none;"`.
  - Внутри: `.main-menu-dropdown-backdrop` (подложка) и `.main-menu-dropdown-content` (панель с пунктами внизу).

- **Z-index (до правки):**
  - Кнопка меню `.menu-btn`: **10012**
  - Нижний `header` (панель с корзиной, избранным и т.д.): **10010**
  - Выпадающее меню `#main-menu-dropdown`: **10008**

Итог: выпадающее меню рисовалось **под** header'ом. Нижняя панель перекрывала и backdrop, и контент меню, перехватывала клики. Поэтому:
- фон не затемнялся в области под header'ом (backdrop был под ним);
- клики по «фону» попадали в header, а не в backdrop → меню не закрывалось;
- клики по пунктам меню в нижней зоне тоже могли попадать в header.

---

## Логика открытия/закрытия (JS)

- **Файл:** `webapp/js/menu.js`.
- Открытие: `menuDropdown.style.display = 'block'`.
- Закрытие: `menuDropdown.style.display = 'none'`.
- Клик по backdrop или по самому dropdown (но не по content) вызывает `closeMenu()`.
- Кнопка меню (гамбургер) при открытии превращается в крестик и закрывает меню при повторном клике.

---

## Стили (CSS): от чего зависит видимость и клики

1. **Контейнер** `.main-menu-dropdown`:
   - По умолчанию: `pointer-events: none` (клики проходят сквозь него).
   - В открытом состоянии (селектор по `style` с `display: block` / `display:block`) должно быть:
     - `pointer-events: auto` — чтобы клики доходили до backdrop и content.
     - **z-index выше header** — иначе header перекрывает меню и «съедает» клики.

2. **Backdrop** `.main-menu-dropdown-backdrop`:
   - По умолчанию: `opacity: 0`.
   - В открытом состоянии (родитель с `display: block` / `display:block`): `opacity: 1` — тогда фон затемняется.

3. **Контент** `.main-menu-dropdown-content`:
   - По умолчанию: `transform: translateY(100%)` (уехал вниз).
   - В открытом состоянии: `transform: translateY(0)` — панель выезжает снизу.

Селекторы открытого состояния в CSS используют `[style*="display: block"]`. Для устойчивости к разному формату атрибута добавлен вариант `[style*="display:block"]` (без пробела).

## Что исправлено (рефакторинг)

1. **Z-index при открытом меню**  
   Для открытого состояния задаётся `z-index: 10011 !important`. Порядок слоёв:
   - 10012 — кнопка меню (всегда сверху, можно закрыть меню).
   - 10011 — выпадающее меню (backdrop + content) — **выше** header и всех страниц (z-index: 1000).
   - 10010 — header.
   - 1000 — страницы (product-page, cart-page-new, favorites-page и т.д.).

   `!important` добавлен, чтобы страницы не могли переопределить z-index меню через inline-стили или другие правила CSS.

2. **Селекторы по атрибуту style**  
   Для открытого меню везде добавлены запасные селекторы:
   - `[style*="display:block"]` (без пробела)
   - `[style*="display: block;"]` (с пробелом и точкой с запятой)
   - `[style*="display:block;"]` (без пробела, с точкой с запятой)
   
   Это гарантирует, что правила срабатывают независимо от формата атрибута `style`.

3. **!important для критичных свойств**  
   Добавлен `!important` для всех критичных свойств открытого меню:
   - `z-index: 10011 !important` — чтобы меню всегда было выше страниц
   - `pointer-events: auto !important` — чтобы гарантировать кликабельность
   - `opacity: 1 !important` для backdrop — чтобы фон всегда затемнялся
   - `transform: translateY(0) !important` для content — чтобы панель всегда была видна

4. **Отсутствие stacking context на контейнере меню**  
   Контейнер `.main-menu-dropdown` не создаёт новый stacking context (нет `transform`, `filter`, `opacity < 1`, `will-change`, `isolation`), чтобы меню всегда было в корневом контексте и z-index работал правильно.

5. **Экспорт функции closeMenu**  
   Функция `closeMenu()` экспортируется из `menu.js` для использования в других модулях при необходимости явного закрытия меню.

---

## Проверка

- Открыть меню (гамбургер) → панель снизу видна, фон затемнён.
- Клик по затемнённому фону → меню закрывается.
- Клик по пункту (Профиль / Настройки / Админка) → меню закрывается и выполняется действие.
- Кнопка меню (крестик) при открытом меню закрывает меню.

Откат: в `webapp/css/style.css` у `.main-menu-dropdown[style*="display: block"]` (и варианта с `display:block`) убрать `z-index: 10011` и дублирующие селекторы для backdrop/content — тогда снова будет старое поведение (меню под header).
