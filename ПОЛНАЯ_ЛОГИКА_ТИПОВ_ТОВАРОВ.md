### 🔄 Логика работы тумблеров

#### 1.1. Определение типа товара при открытии формы

```javascript
// Строки 188-200
const isForSale = prod.is_for_sale === true || 
                  prod.is_for_sale === 1 || 
                  prod.is_for_sale === '1' ||
                  prod.is_for_sale === 'true' ||
                  String(prod.is_for_sale).toLowerCase() === 'true';

const isMadeToOrder = prod.is_made_to_order === true || 
                      prod.is_made_to_order === 1 || 
                      prod.is_made_to_order === '1' ||
                      prod.is_made_to_order === 'true' ||
                      String(prod.is_made_to_order).toLowerCase() === 'true';
```

**Важно:** Проверка идет через множественные сравнения, потому что значения могут приходить из БД в разных форматах (boolean, int, string).

#### 1.2. Два режима формы редактирования

**Режим 1: Товар для продажи (`is_for_sale = true`)**

```javascript
// Строки 206-336
if (isForSale) {
    // Скрываем обычные поля
    editPriceField.style.display = 'none';
    editQuantityField.style.display = 'none';
    editMadeToOrderField.style.display = 'none';
    editSaleEnabledField.style.display = 'none';
    editReservationEnabledField.style.display = 'none';
    
    // Показываем поля для продажи
    forSaleFields.style.display = 'block';
    
    // Заполняем поля:
    // - price_type: 'range' или 'fixed'
    // - price_from, price_to (для range)
    // - price_fixed (для fixed)
    // - quantity_from, quantity_unit
}
```

**Режим 2: Обычный товар (`is_for_sale = false`)**

```javascript
// Строки 336-451
else {
    // Показываем обычные поля
    editPriceField.style.display = 'block';
    editQuantityField.style.display = 'block';
    editMadeToOrderField.style.display = 'block';
    editSaleEnabledField.style.display = 'block';
    editReservationEnabledField.style.display = 'block';
    
    // Скрываем поля для продажи
    forSaleFields.style.display = 'none';
    
    // Устанавливаем тумблеры:
    // - editMadeToOrderInput.checked = isMadeToOrder
    // - editSaleEnabledInput.checked = isSaleEnabled
    // - editReservationEnabledInput.checked = isReservationEnabled
}
```

#### 1.3. Взаимоисключение тумблеров

**Правило:** Только один из трех режимов может быть активен одновременно.

**Приоритет:**
1. `is_sale_enabled` (Продажа) - высший приоритет
2. `is_made_to_order` (Под заказ) - средний приоритет
3. `is_reservation_enabled` (Резервация) - низший приоритет

```javascript
// Строки 405-451
// Нормализация: только один из трёх режимов
const count = (isSaleEnabled ? 1 : 0) + (isMadeToOrder ? 1 : 0) + (isReservationEnabled ? 1 : 0);
if (count > 1) {
    if (isSaleEnabled) {
        isMadeToOrder = false;
        isReservationEnabled = false;
    } else if (isMadeToOrder) {
        isReservationEnabled = false;
    }
    // Обновляем UI
}

// Обработчики изменения тумблеров
editMadeToOrderInput.onchange = () => {
    const madeToOrderEnabled = editMadeToOrderInput.checked;
    editQuantityShowEnabledInput.disabled = madeToOrderEnabled;
    if (madeToOrderEnabled) {
        editSaleEnabledInput.checked = false;
        editReservationEnabledInput.checked = false;
    }
};

editSaleEnabledInput.onchange = () => {
    if (editSaleEnabledInput.checked) {
        editMadeToOrderInput.checked = false;
        editReservationEnabledInput.checked = false;
        editQuantityShowEnabledInput.disabled = false;
    }
};

editReservationEnabledInput.onchange = () => {
    if (editReservationEnabledInput.checked) {
        editSaleEnabledInput.checked = false;
        editMadeToOrderInput.checked = false;
        editQuantityShowEnabledInput.disabled = false;
    }
};
```

#### 1.4. Сохранение изменений

```javascript
// Строки 692-704
let newSaleEnabled = !!(editSaleEnabledInput && editSaleEnabledInput.checked);
let newMadeToOrder = !!(editMadeToOrderInput && editMadeToOrderInput.checked);
let newReservationEnabled = !!(editReservationEnabledInput && editReservationEnabledInput.checked);

// Применяем взаимоисключение при сохранении
if (newSaleEnabled) {
    newMadeToOrder = false;
    newReservationEnabled = false;
} else if (newMadeToOrder) {
    newSaleEnabled = false;
    newReservationEnabled = false;
} else if (newReservationEnabled) {
    newSaleEnabled = false;
    newMadeToOrder = false;
}

// Отправляем на сервер через отдельные API-вызовы
await updateProductSaleEnabledAPI(productId, appContext.shop_owner_id, newSaleEnabled);
await updateProductMadeToOrderAPI(productId, appContext.shop_owner_id, newMadeToOrder);
await updateProductReservationEnabledAPI(productId, appContext.shop_owner_id, newReservationEnabled);
```

### 🔄 Логика определения типа действия

#### 3.1. Единый helper для определения типа

```javascript
// Файл: webapp/js/utils/productActionType.js
// Строки 10-91

export function getProductActionType(product, appContext, shopSettings) {
    // Преобразуем boolean значения
    const isForSale = product.is_for_sale === true || 
                     product.is_for_sale === 1 || 
                     product.is_for_sale === '1' ||
                     product.is_for_sale === 'true' ||
                     String(product.is_for_sale).toLowerCase() === 'true';
    
    const isSaleEnabled = product.is_sale_enabled === true || 
                         product.is_sale_enabled === 1 || 
                         product.is_sale_enabled === '1' ||
                         product.is_sale_enabled === 'true' ||
                         String(product.is_sale_enabled).toLowerCase() === 'true';
    
    const isMadeToOrder = product.is_made_to_order === true || 
                         product.is_made_to_order === 1 || 
                         product.is_made_to_order === '1' ||
                         product.is_made_to_order === 'true' ||
                         String(product.is_made_to_order).toLowerCase() === 'true';
    
    const isReservationEnabled = product.is_reservation_enabled === true || 
                                product.is_reservation_enabled === 1 || 
                                product.is_reservation_enabled === '1' ||
                                product.is_reservation_enabled === 'true' ||
                                String(product.is_reservation_enabled || '').toLowerCase() === 'true';

    // СТРОГИЙ ПРИОРИТЕТ (без исключений):
    // 1. is_for_sale → 'purchase' (клиент продает магазину)
    if (isForSale && appContext && appContext.role === 'client') {
        return 'purchase';
    }
    
    // 2. is_client_sale → 'sale' (клиент продает клиенту - C2C)
    if (isClientSale && appContext && appContext.role === 'client') {
        return 'sale';
    }
    
    // 3. is_sale_enabled → 'sale' (магазин продает клиенту)
    if (isSaleEnabled && appContext && appContext.role === 'client') {
        return 'sale';
    }
    
    // 4. is_made_to_order → 'order' (заказ)
    if (isMadeToOrder && appContext && appContext.role === 'client') {
        return 'order';
    }

    // 5. is_reservation_enabled → 'reserve' только если резервации разрешены
    if (isReservationEnabled && appContext && appContext.role === 'client') {
        const reservationsEnabled = shopSettings ? (shopSettings.reservations_enabled === true) : true;
        const canReserve = appContext.permissions && appContext.permissions.can_reserve && reservationsEnabled;
        if (canReserve) {
            return 'reserve';
        }
        return 'none';
    }

    // 6. canReserve (авто) → 'reserve' — товар без явного флага, но подходит под резервацию
    if (appContext && appContext.role === 'client') {
        const reservationsEnabled = shopSettings ? (shopSettings.reservations_enabled === true) : true;
        const canReserve = appContext.permissions && 
                          appContext.permissions.can_reserve && 
                          reservationsEnabled &&
                          !isMadeToOrder;
        if (canReserve && !isSaleEnabled && !isClientSale) {
            return 'reserve';
        }
    }

    // 7. иначе → 'none'
    return 'none';
}
```

#### 3.3. Использование в Bottom Sheet

```javascript
// Файл: webapp/js/cart/cartBottomSheet.js
// Строки 487-600

primaryBtnHandler = async () => {
    if (!currentProduct) return;
    
    const appContext = window.getAppContext ? window.getAppContext() : null;
    if (!appContext) return;
    
    // Загружаем helper если еще не загружен
    await loadProductActionTypeHelper();
    
    // Получаем тип операции через единый helper
    const shopSettings = window.getCurrentShopSettings ? window.getCurrentShopSettings() : null;
    const actionType = getProductActionType(currentProduct, appContext, shopSettings);
    
    // Выполняем действие в зависимости от типа операции
    closeBottomSheet();
    
    switch (actionType) {
        case 'purchase':
            // Продать - когда клиент продает нам
            const { showPurchasePage } = await import('../purchases.js');
            showPurchasePage(currentProduct);
            break;
            
        case 'sale':
            // Купить — единый поток через Deal
            const { startDealCheckoutAPI } = await import('../api/deals.js');
            const { openDealCheckoutPage } = await import('../dealCheckout.js');
            const quantity = quantityInput ? Math.max(1, parseInt(quantityInput.value) || 1) : currentQuantity;
            const result = await startDealCheckoutAPI({
                items: [{ product_id: currentProduct.id, quantity }],
            });
            openDealCheckoutPage(result.deal_id, {
                total_items_count: result.total_items_count,
                total_amount: result.total_amount,
                currency: result.currency,
            }, { source: 'single' });
            break;
            
        case 'order':
            // Заказать - когда клиент делает заказ
            const { showOrderPage } = await import('../orders.js');
            showOrderPage(currentProduct.id, false);
            break;
            
        case 'reserve':
            // Резервировать - когда клиент делает резервацию
            const { showReservationModal } = await import('../reservations.js');
            showReservationModal(currentProduct.id);
            break;
            
        default:
            // Для остальных товаров - просто закрываем bottom sheet
            break;
    }
};
```

#### 4.2. Рендеринг кнопки действия на карточке товара

```javascript
// Файл: webapp/js/handlers/products_render.js
// Строки 384-477

// Создаем кнопку действия (левый нижний угол) - только для клиентов и только на странице избранного
let actionButton = null;
const favoritesPage = document.getElementById('favorites-page');
const isOnFavoritesPage = favoritesPage && (favoritesPage.style.display === 'block' || favoritesPage.style.display === 'flex');

if (isClient && isOnFavoritesPage) {
    // Получаем тип операции через единый helper
    const currentAppContextForAction = appContextGetter ? appContextGetter() : null;
    const shopSettings = getCurrentShopSettings();
    const actionType = getProductActionType(prod, currentAppContextForAction, shopSettings);
    const actionIcon = getActionIcon(actionType);
    
    // Показываем кнопку только если есть действие
    if (actionIcon) {
        actionButton = document.createElement('button');
        actionButton.className = 'cart-button-card';
        actionButton.setAttribute('aria-label', 'Действие с товаром');
        actionButton.dataset.productId = prod.id;
        actionButton.dataset.actionType = actionType;
        
        // Иконка действия в зависимости от типа (эмодзи)
        actionButton.innerHTML = `
            <span class="action-icon" style="font-size: 24px; line-height: 1;">${actionIcon}</span>
            <span class="cart-icon-badge" style="display: none;">0</span>
        `;
        
        // Для типа 'sale' показываем badge с количеством из корзины
        if (actionType === 'sale') {
            setTimeout(() => {
                import('../cart/cartStore.js').then(({ isProductInCart, getProductQuantityInCart }) => {
                    const quantity = getProductQuantityInCart(prod.id);
                    if (quantity > 0) {
                        actionButton.classList.add('cart-active');
                        const badge = actionButton.querySelector('.cart-icon-badge');
                        if (badge) {
                            badge.textContent = quantity > 99 ? '99+' : quantity.toString();
                            badge.style.display = 'flex';
                        }
                    }
                }).catch(() => {});
            }, 0);
        }
        
        // Обработчик клика на кнопку действия
        actionButton.addEventListener('click', async (e) => {
            e.stopPropagation();
            e.preventDefault();
            
            // Проверяем, что мы все еще на странице избранного
            const favoritesPage = document.getElementById('favorites-page');
            const isOnFavoritesPage = favoritesPage && (favoritesPage.style.display === 'block' || favoritesPage.style.display === 'flex');
            
            if (!isOnFavoritesPage) {
                return;
            }
            
            try {
                // Получаем тип операции через единый helper
                const appContext = window.getAppContext ? window.getAppContext() : null;
                const shopSettings = window.getCurrentShopSettings ? window.getCurrentShopSettings() : null;
                const actionType = getProductActionType(prod, appContext, shopSettings);
                
                // Для типа 'sale' добавляем товар в корзину, если его там нет
                if (actionType === 'sale') {
                    const { isProductInCart, getProductQuantityInCart } = await import('../cart/cartStore.js');
                    const isInCart = isProductInCart(prod.id);
                    const currentQuantity = getProductQuantityInCart(prod.id);
                    
                    if (!isInCart || currentQuantity === 0) {
                        const { addProductToCart } = await import('../cart/cartNew.js');
                        await addProductToCart(prod, 1);
                    }
                }
                
                // Открываем bottom sheet (он сам определит правильную кнопку через helper)
                const { showCartBottomSheet } = await import('../cart/cartBottomSheet.js');
                await showCartBottomSheet(prod);
                
                // Обновляем состояние кнопок корзины
                if (window.updateCartButtonsState) {
                    window.updateCartButtonsState();
                }
            } catch (error) {
                console.error('❌ Error showing bottom sheet:', error);
                alert('Ошибка: ' + (error.message || 'Неизвестная ошибка'));
            }
        });
    }
}
```

#### 4.3. Позиционирование иконок

**На карточке товара (режим сетки):**
- **Кнопка избранного:** правый нижний угол фото (`right: 8px; bottom: 8px`)
- **Кнопка действия:** левый нижний угол фото (`left: 8px; bottom: 8px`)

**На карточке товара (режим списка):**
- **Кнопка избранного:** правый верхний угол карточки
- **Кнопка действия:** правая часть карточки, над статусом товара

### 🔍 Почему иконки не меняются в зависимости от типа товара?

#### Проблема 1: Кэширование данных

**Симптом:** Иконки не обновляются после изменения типа товара.

**Причина:** Данные товаров кэшируются в `allProducts`, и после редактирования кэш не обновляется.

**Решение:**
```javascript
// Файл: webapp/js/product-edit.js
// Строки 953-975

// Подставляем в allProducts свежие данные по обоим ID (редактируемый и client-visible)
if (allProductsGetter && allProductsSetter && (freshOwnerProduct || freshClientProduct)) {
    const list = allProductsGetter();
    if (Array.isArray(list) && list.length > 0) {
        let changed = false;
        const next = list.map(p => {
            if (!p || p.id == null) return p;
            if (freshOwnerProduct && p.id === freshOwnerProduct.id) {
                changed = true;
                return freshOwnerProduct;
            }
            if (freshClientProduct && p.id === freshClientProduct.id) {
                changed = true;
                return freshClientProduct;
            }
            return p;
        });
        if (changed) {
            allProductsSetter(next);
            if (applyFiltersCallback) applyFiltersCallback();
        }
    }
}
```

#### Проблема 2: Неправильное определение типа действия

**Симптом:** Иконка не соответствует типу товара.

**Причина:** Значения флагов приходят из БД в разных форматах (boolean, int, string).

**Решение:** Использовать единый helper `getProductActionType`, который нормализует все форматы:
```javascript
// Файл: webapp/js/utils/productActionType.js
// Строки 16-44

// Преобразуем boolean значения из разных форматов
const isForSale = product.is_for_sale === true || 
                 product.is_for_sale === 1 || 
                 product.is_for_sale === '1' ||
                 product.is_for_sale === 'true' ||
                 String(product.is_for_sale).toLowerCase() === 'true';
```

#### Проблема 3: Иконки не обновляются на странице избранного

**Симптом:** После редактирования товара иконки на странице избранного остаются старыми.

**Причина:** Страница избранного не перезагружается после редактирования.

**Решение:**
```javascript
// Файл: webapp/js/product-edit.js
// Строки 997-1003

// Избранное: перезагрузить страницу (иконки действий на карточках строятся по getProductActionType(prod))
const favoritesPageEl = document.getElementById('favorites-page');
if (favoritesPageEl && (favoritesPageEl.style.display === 'block' || favoritesPageEl.style.display === 'flex')) {
    try {
        if (typeof window.loadFavoritesPage === 'function') await window.loadFavoritesPage();
    } catch (_) {}
}
```

## 📝 ВЫВОДЫ

### Ключевые моменты:

1. **Тип товара определяется флагами в БД:**
   - `is_for_sale` - товар для покупки (клиент продает магазину)
   - `is_sale_enabled` - товар для продажи (магазин продает клиенту)
   - `is_made_to_order` - товар под заказ
   - `is_reservation_enabled` - товар с резервацией

2. **Приоритет типов строгий:**
   - Покупка → Продажа → Под заказ → Резервация → Обычный

3. **Единый источник истины:**
   - `getProductActionType()` - определяет тип действия
   - `getActionIcon()` - возвращает иконку
   - `getActionButtonText()` - возвращает текст кнопки

4. **Взаимоисключение тумблеров:**
   - Только один из трех режимов может быть активен
   - При включении одного другие автоматически выключаются

5. **Обновление UI:**
   - После редактирования товара необходимо обновить кэш
   - Перезагрузить страницу избранного
   - Обновить bottom sheet с новыми данными

### Рекомендации для исправления проблем:

1. **Всегда используйте `getProductActionType()`** для определения типа товара
2. **Обновляйте кэш `allProducts`** после редактирования товара
3. **Перезагружайте страницу избранного** после сохранения изменений
4. **Проверяйте формат данных** из БД (может быть boolean, int, string)
5. **Используйте единый helper** для всех операций с типами товаров
